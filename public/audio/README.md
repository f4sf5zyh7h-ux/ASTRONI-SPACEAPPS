# Voice lines (optional)

Drop recorded `.mp3` files here with these exact names. The game plays them through a radio filter instead of the browser voice. Missing files fall back to the browser voice automatically.

| File | Line (Mission Control) |
|---|---|
| `intro-1.mp3` | AURORA-7, telemetry looks good. Science downlink at one hundred percent. |
| `intro-2.mp3` | Hold on. Tracking shows a debris fragment on a crossing path. |
| `intro-3.mp3` | Debris hits at around ten kilometres per second. That's about ten times faster than a rifle bullet. |
| `intro-4.mp3` | Impact! Solar array B is gone. AURORA-7 is running on battery. |
| `intro-5.mp3` | The battery lasts seventy-two hours. Then the instruments shut down, and the data on board is lost. |
| `intro-6.mp3` | We depend on its data getting back to Earth. Go up, retrieve the data, fix the satellite, fly home. |

Tips: record in a quiet room, speak calmly and a little fast (like real mission control), trim the silence at the start. Phone voice memos are fine — convert to mp3 if needed.
